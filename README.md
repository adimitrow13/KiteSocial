# KiteSocial.API

A kitesurfing social network backend API built with ASP.NET Core (.NET 10).

## Tech Stack
- **Framework**: .NET 10 (`net10.0`) / ASP.NET Core Web API
- **API Documentation**: OpenAPI / Swagger

## Getting Started

### Prerequisites
- [.NET 10 SDK](https://dotnet.microsoft.com/download)

### Run locally
```bash
dotnet restore
dotnet run
```
